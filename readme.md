## 关键机制

> 关键规则

1. 追击：身后有“暗雾”追击玩家，玩家被暗雾抓到，则游戏失败
2. 跳跃
   1. 类似马里奥的跳跃机制，可以跳过障碍物
3. 转换
   1. 横板卷轴关卡，地面和天花板都有障碍物关卡设计
   2. 角色可以瞬间在地面和天花板之间做转换，整个游戏视角也会同时跟着角色反转
4. 胜负条件
   1. 被暗雾抓到，则游戏失败
   2. 触发陷阱，则游戏失败
   3. 到达终点，则游戏胜利

## 玩法

1. 根据当前关卡实际情况进行路线选择
2. 躲避陷阱、快速越过障碍
3. 尽量短时间内到达终点
4. 不要让暗雾追到
